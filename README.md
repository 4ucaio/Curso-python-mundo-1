# 🐍 Curso de Python - Mundo 1

Este repositório contém exercícios e atividades desenvolvidos durante o **Curso de Python - Mundo 1**, com foco em fundamentos da linguagem. Os arquivos foram organizados conforme o progresso no conteúdo.

## 📚 Conteúdo abordado

- Variáveis e Tipos Primitivos
- Entrada e Saída de Dados
- Operações Aritméticas
- Manipulação de Strings
- Condicionais (if/else)
- Estruturas de Repetição (while)
- Exercícios práticos de fixação

## 📁 Estrutura dos arquivos

Todos os arquivos `.py` estão diretamente na raiz da pasta e seguem a ordem das aulas e exercícios propostos no curso. Exemplos de nomes de arquivos:

- `ex001.py` – Primeiro programa em Python
- `ex002.py` – Manipulando texto e entrada de dados
- `ex003.py` – Operações matemáticas básicas
- ...
